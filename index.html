Movie Ticket Booking
Try it How it works C code Team

Book a seat. Wait your turn.

Choose your own seats on the map, then your request lines up in a queue, so the first person to ask is the first to be confirmed. Confirmed tickets pile onto a stack, so the latest booking is the first one you can cancel. Every movie has its own screen and its own seats.

Try it

Pick a movie, tap the seats you want, and join the queue. Then confirm the next request in line. Seats are tracked separately for each movie.

        How it works

        The project is a menu-driven C program. This page runs the same logic in the browser so you can see the structures move.

        Queue: first in, first out

        Booking requests are added at the rear and served from the front. Nobody can skip ahead, which keeps booking fair.

        201202203

        Front is on the left, rear is on the right.

        Stack: last in, first out

        A confirmed booking is pushed on top. Cancelling pops the top booking and returns its seats to the movie it was for.

        203 (top)202201

        One screen per movie

        Each movie is a small structure with its own name and its own seat map (rows A and B, ten seats each). The customer picks exact seats, and a booking remembers both the movie and those seats. The moment a request joins the queue its seats are held, so nobody else can pick them while it waits. Confirming moves the booking onto the stack, and cancelling pops it and frees those exact seats in the same movie only.
